## 전환·텍스트 모션 (Neo 1X 케이스 스터디 참고)

화면(`<section class="slide">`)과 요소에 속성만 붙이면 적용됩니다.

| 속성 | 효과 |
| --- | --- |
| `data-tr="blur"` (기본) | 블러 디졸브: 이전 화면이 흐려지며 사라지고 다음 화면이 흐림에서 선명해짐 |
| `data-tr="push"` | 세로 푸시: 이전 화면이 위로 밀려 나가고 다음 화면이 아래에서 올라옴 |
| `data-tr="zoom"` | 줌 스루: 이전 화면이 확대되며 흐려지고 다음 화면이 작게 시작해 제자리로 |
| `data-tr="cut"` | 하드 컷 |
| `data-words` | 단어별 순차 등장 (아래에서 올라오며 블러 해제) |
| `data-stagger` | 자식 요소(행·카드)를 하나씩 등장 |
| `data-count="87" data-suffix="M"` | 숫자 카운트업 (`data-prefix`, `data-dec` 지원) |
| `class="fu" style="--i:N"` | 블록 단위 페이드 업, N 순서대로 |

주소 뒤에 `?tr=push` 처럼 붙이면 모든 화면에 한 가지 전환을 강제해 비교할 수 있습니다.
