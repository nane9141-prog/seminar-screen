세미나 송출용 크롬 실행 파일 (Windows)

더블클릭하면 세미나 전용 크롬(평소 크롬과 분리된 프로필 C:\seminar-chrome)이 최적화 설정으로 열립니다.

  1_main_screen.bat              메인 스크린(21:8) 전체화면
  1b_main_screen_LED_stretch.bat 메인 스크린 — LED 프로세서가 1920×1080을 받아 늘리는 경우(?out=led)
  2_control.bat                  운영 입력 — 메인과 같은 PC면 1번을 먼저 실행한 뒤
  3_mc_script.bat                사회자 대본
  4_led_4x3.bat                  양쪽 LED(4:3)
  5_projector_16x9.bat           빔프로젝터(16:9)
  0_reset_chrome_profile.bat     세미나 전용 크롬 설정 초기화(문제 생길 때만)

적용되는 설정
  - 소리 자동재생 허용(클릭 안 해도 효과음 · 배경음 재생)
  - 웹 알림 · 위치 요청 · 번역 바 · 비밀번호 저장 · 기본 브라우저 묻기 · 첫 실행 안내 끔
  - "크롬이 제대로 종료되지 않았습니다" 복원 안내 끔, 오류 대화상자 끔
  - 창이 가려지거나 뒤에 있어도 타이머 · 애니메이션이 느려지지 않게(휴식 타이머 · 연동 유지)
  - 행사 중 크롬 구성요소 자동 업데이트 끔, 두 손가락 확대 · 스와이프 뒤로 가기 끔
  - 주소창 · 탭 없는 앱 창 + 전체화면(메인 · LED · 프로젝터 · 사회자)

모니터 위치
  메인 · LED · 프로젝터 파일 안 set "X=0" 을 그 화면이 연결된 모니터의 왼쪽 위치로 바꿉니다.
  예) 노트북 화면 오른쪽에 두 번째 모니터(메인 스크린) → set "X=1920"
  Windows 디스플레이 설정에서 "여러 디스플레이: 디스플레이 확장"으로 둡니다.

주의
  - 처음 한 번은 세미나 전용 크롬이라 화면 공유 · 카메라 권한을 다시 허용해야 합니다(세션 3 화상).
  - 전체화면 해제는 F11 또는 Esc, 창 닫기는 Alt+F4.
  - 인터넷 없이 같은 PC에서만 연동할 때는 주소 끝에 ?net=0 (메인 · 운영 입력 둘 다).

Windows 설정 체크리스트(송출 PC)
  [ ] 알림 끄기: 설정 > 시스템 > 알림 > 끔, 방해 금지(집중 지원) 켬
  [ ] 절전 · 화면 끄기 · 최대 절전 "안 함", 화면 보호기 없음
  [ ] Windows 업데이트 일시 중지(1주), 재시작 예약 없음
  [ ] 디스플레이 배율 100%, 해상도는 스크린 입력 해상도와 같게
  [ ] 작업 표시줄 자동 숨기기, 메신저 · 백신 팝업 앱 종료(카카오톡 · 팀즈 · 아웃룩 알림)
  [ ] 소리 출력 장치 = 믹서로 가는 출력(HDMI · 오디오 인터페이스), 시스템 효과음 끔
  [ ] 유선 인터넷 연결, 와이파이 자동 전환 끔
